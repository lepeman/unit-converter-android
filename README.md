📱 Unit Converter (Android)

Simple unit converter application developed with Kotlin and Jetpack Compose.

This project is intended as a minimal Android application to maintain an active Google Play Developer account.

🚀 Version

v0.1

Initial release with basic unit conversion functionality.

🛠 Tech Stack

Kotlin

Jetpack Compose

Material 3

🔒 Privacy Policy

This application does not collect, store, share, or transmit any personal or sensitive user data.

No user accounts

No analytics

No ads

No internet connection required

No third-party services

The app works fully offline and performs all calculations locally on the device.
